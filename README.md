# Filtro Vasarely

Web app que convierte la cámara (en vivo) o una foto en una ilusión óptica al estilo de Victor Vasarely.

- 6 filtros: Cebras, Esfera, Mosaico, Líneas, Unidades y Cubos
- 2 paletas: Vasarely clásico y Tricolor húngaro
- Ajustes en vivo: intensidad, tamaño de trama, contraste, invertir, espejo
- Descarga en PNG (1200 px de ancho)

Es un solo archivo (`index.html`), sin dependencias. Todo se procesa en el dispositivo; las fotos no se suben a ningún servidor.
